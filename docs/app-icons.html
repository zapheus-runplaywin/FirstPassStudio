1P Studio app icon · PR #46 + #47

Before and after for the Mac app icon, menu bar icon and browser favicon in FirstPass Studio.

Icons, before and after

The Dock and Finder icons and the menu bar icon arrived in PR #46 (merged). The menu bar icon is a macOS template image, so it turns black or white with the menu bar. The browser tab favicon is new in PR #47; before it, tabs showed a blank default.

Logo files

Traced from Matt's 1P Studio icon set as vectors, in public/studio/1p-studio-light.svg and 1p-studio-dark.svg. The app icon and favicon are cut from the dark one.
