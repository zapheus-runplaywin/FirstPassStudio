A link set is a key for a Stream Deck's Website keys: make one per Stream Deck, pick it on the Output page or the Stream Deck page, and its links carry its own key, so one can be given a new key or removed without the others. Link sets never run out. The Studio Stream Deck plugin asks to be added on its first key press and then signs every press with its own key pair; once one has been allowed, plugins that haven't can't press anything. Studio's own pages on this Mac always can change things, and while "Only this Mac can change things" is ticked in the menu bar icon (it is each time Studio opens), nothing else can. A program on another device can ask to be added (the Docs page says how): the Mac asks you to Allow or Deny it, and it shows here too. A device unused for 90 days drops off the list and has to ask again.
