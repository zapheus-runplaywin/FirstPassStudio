Control page settings (every page follows these)

Every graphic uses the round, game and court set on the scoreboard control page. A setting added to a page's own link (like ?division=2 or ?round=6) overrides it for that page only.

  • Round: Automatic picks the round played in the next 5 days, counting today, so a Tuesday round is picked from the Friday before. Otherwise it's the last round played (roundLookaheadDays in config.json). Pick a round from the list to test with it, then set it back to Automatic.
  • Always a game on: when the helper starts, or the scoreboard is cleared, it puts a game on straight away with Follow PlayHQ on: the game for now on the court, otherwise this round's first game on that court, otherwise this round's first game. The board is only left empty if PlayHQ can't be reached or the competition isn't found (check organisationUrl and competitionName in config.json).
  • Game: tick Pick the game automatically for court and set the court (default defaultCourt in config.json, e.g. Indoor 01 or just 1). It shows the first game of the day on that court, then switches to each next game 10 minutes before it starts, with the quarter back to Q1 and a full clock. A final (a round with "Final" in its name) stays on until PlayHQ marks it finished, in case of extra time. With a round picked by hand, its games are treated as if they were today, so the switching can be tested any time.
  • Overrides: picking a game from the list turns automatic selection off until you tick it again or change the court. Pressing a score button switches scores to manual, and any clock button switches the clock to manual.
  • Follow PlayHQ: the score and quarter come from PlayHQ's live scoring every 5 seconds. Tick Follow the PlayHQ scorer's clock to run the clock from the scorer's clock too.
  • Pages that use the picked game's division: ladder (without ?division=), ladder bar, top shooters, title, match up, The Clash, team lists, shooting stats and full time. The fixture, results, ticker and up next use the round.
  • Stream Deck: /deck/auto/on, /deck/auto/off, /deck/auto/toggle, /deck/court/2 and /deck/clock/playhq/on. See the Stream Deck API docs above for the rest.

Data and bandwidth

Only scoreboard.html and ticker.html keep asking for new data (the control page does too, but it isn't in OBS). Every other graphic gets its data once when it loads, so tick Refresh browser when scene becomes active in OBS to update it. The Clash only retries if the helper isn't running.

Pages only ever talk to the helper on this computer, which uses no internet. The helper is the only thing that contacts PlayHQ, and it caches what it gets:

  • Scoreboard following PlayHQ: one small request every 5 seconds (Check PlayHQ every on the control page).
  • Ticker: other courts' scores at most every 30 seconds.
  • Automatic game selection: the fixture about once a minute for the current round, every 10 minutes for the rest.

Each answer is a few kilobytes, well under 1 MB an hour in total. Two options make a page poll, both off unless you add them: ?refresh= on the ladder, and &reload= on the scoreboard and control page.

Something not working? The debug log is in the logs folder, or open the debug log. Send logs/playhq-graphics.log to Claude.

In OBS add a Browser source, paste a link, and set width 1920 and height 1080. Toggle each source's visibility to show or hide it.
