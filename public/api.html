Stream Deck

Run the scene and the scoreboard from a Stream Deck; Studio has to be on air, so keep a Studio window open. More in the Docs

Each link set has its own key: make one per Stream Deck, and Devices… can give one a new key or remove it without touching the others.

Scene and sources: the FirstPass Studio plugin

For Studio's own scene, built on the Output page. The Mac app includes a Stream Deck plugin. Install it with the button below (or Install the Stream Deck plugin in the menu bar icon); the Stream Deck app opens it and installs it. Do it again after an app update to update the plugin.

Then drag FirstPass Studio › Source onto a key and pick the source in its settings.

  • Press: show or hide (the default), fade in, fade out, refresh the page or restart the video, or turn the video's sound on or off.
  • The key shows the source's name and lights up orange while the source is on, however it was turned on. A sound key lights while the video's sound is on.
  • It follows the source itself, so renaming the source doesn't break the key. A removed source says gone; while Studio isn't running it says off air.
  • FirstPass Studio › Scene goes to a saved scene; FirstPass Studio › Sequence plays a sequence, or presses Next, Pause or Stop for whatever is playing. It lights up while its sequence plays and shows the step and time left, like 3/5 0:12. Its Time left setting picks the step's, the whole sequence's (all 1:40; + when part of it waits, ↻ when it repeats), both, or none. When a sequence is about to start by itself, its key counts down to it (in 0:04).
  • FirstPass Studio › Switcher presses the ATEM picked on the Output page's Switcher card: a camera to preview or straight to program, a stinger, Cut, Auto, a key, Fade to black or a macro. A camera's key lights red while it's on program and green on preview, like the switcher's own buttons, and a key or Fade to black lights red while on air. While the switcher isn't answering the key goes dark with a yellow dot and a press does nothing.
  • FirstPass Studio › Replay plays or pauses, jumps, nudges or stops the 4K replay or practice game started on the Recordings tab, whichever is running, and lights while one runs.
  • The five kinds look different at a glance: a Source key has a faint eye and one strip along the bottom, a Scene key stacked layers and a frame in its colour round the key, a Sequence key a play button and its strip split into four steps, a Switcher key a camera and its strip in two halves, and a Replay key play and pause with a timeline and its playhead.
  • Studio in its settings stays empty when the Stream Deck is on the same Mac; for another Mac type its address, like http://studio-mac.local:8080.

No plugin? Every source also has links for a Website action (the Output page copies them), but those keys don't light up. The links below for the whole scene and the video output work the same way. A sequence plays from /deck/sequence/<name> (/deck/sequence/<name>/toggle stops it on a second press); the Output page shows each one's link. Links copied here carry this Mac's Stream Deck key after the port (/k/…), so a web page can't press them; the plugin needs none. A link without the key is refused, so copy older links again from here. To give up the key (a link got out), choose Devices… on the Mac and Make a new key.

Manual scoring and timing

These links stop Follow PlayHQ.

  • Any score link (+1, +2, −1, −2, reset) switches the scoreboard to Manual: it stops taking the score from PlayHQ, and the clock stops following the PlayHQ scorer too.
  • Any clock link (start, stop, reset, set, adjust) stops the clock following the PlayHQ scorer. The score keeps following PlayHQ.
  • Quarter links don't switch anything off, but while following PlayHQ the scorer's next quarter change still wins.
  • To go back, press Follow PlayHQ (it turns the score and the clock back on), or Follow the PlayHQ scorer's clock for the clock only. Picking a game on Scoreboard control also turns Follow PlayHQ back on.

Each link goes in a System › Website action with GET request in background ticked, so no browser opens. These links use this Mac's network name, so they also work from a Stream Deck on another computer on the same network.

Scoring mode

Scores (switch to Manual)

Clock (stops following the PlayHQ scorer's clock)

Any amount works in an adjust link (adjust/2m, adjust/-30s), and any time in a set link (set/7:30). /deck/clock/length/12 sets the quarter length in minutes.

Quarter

Changing the quarter doesn't touch the clock: press Reset clock as well when the new quarter starts (a Stream Deck Multi Action can do both).
