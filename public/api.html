Devices

What may change scores, the scene and sequences from somewhere other than this Mac's own windows: Stream Decks and their links, paired phones and programs. Only the Mac running Studio sees and changes the list. More in the guide

DeviceAllowedMadeLast used

A link set is a key for a Stream Deck's Website keys: make one per Stream Deck, pick it here or on the Output page, and its links carry its own key, so one can be given a new key or removed without the others. Link sets never run out. The Studio Stream Deck plugin asks to be added on its first key press and then signs every press with its own key pair; once one has been allowed, plugins that haven't can't press anything. A phone, iPad or another computer pairs from Studio's /pair.html page, allowed to score only or to change everything; a program on another device can ask too (Pairing, under Links below). The Mac asks you to Allow or Deny each one, and it shows here too. Studio's own pages on this Mac always can change things. While "Only this Mac can change things" is ticked in the menu bar icon (it is each time Studio opens), only the devices in this list can as well. A device unused for 90 days drops off the list and has to ask again.

The list of devices shows only on the Mac running Studio.

Secure phone link

A phone's browser lets a page use its microphone or share sheet only over https. Turned on, Studio also answers at its own name on the internet (…studio.firstpass.pivt.au) with a Let's Encrypt certificate, and the phone QR codes use it. Set up once for PIVT, then paste the same three things into each Studio Mac. How to set it up

Stream Deck

Run the scene and the scoreboard from a Stream Deck; Studio has to be on air, so keep a Studio window open.

The FirstPass Studio plugin

Keys for Studio's own scene: sources, scenes, sequences, the run order, the switcher and the replay, each lit by what it does. The Mac app includes the plugin: install it here (or Install the Stream Deck plugin in the menu bar icon) and the Stream Deck app opens and installs it; do it again after an app update. What each key does and shows: The plugin in the guide.

Links

Every link Studio answers, each with what it does: the graphics, to use one on its own, and the Stream Deck links, for a System › Website action with GET request in background ticked (or a Multi Action, or any program on the network). They use this Mac's network name, so they work from other devices on the same network. A Stream Deck link carries a key after the port (/k/…) so no web page can press it; the Studio plugin needs none. A score link switches the scoreboard to Manual, and a clock link stops the clock following the PlayHQ scorer: Follow PlayHQ puts both back. Each graphic's Preview opens it at half size; on the Output page its options are fields in the source's settings.

Each link set has its own key: make one per Stream Deck, and the Devices list above can give one a new key or remove it without touching the others.

Download openapi.yaml for programs: every Stream Deck link and read, in OpenAPI.
