# @firstpass/playhq

## 0.2.0 (2026-11-13)

Moved into FirstPass Studio's repository and published to the public npm registry as
`@firstpass/playhq`, under the MIT licence. Built as CommonJS with type definitions. No API changes.

## 0.1.0 (2026-11-13)

First release, extracted from Studio's `playhq.js` and HQ's `playhq` function:
link parsing for organisation and season links, the GraphQL queries, the guest session, parsers for
competitions, seasons, ladders, rounds, fixtures, line ups and the live feed, HQ's fixture import,
and a memory cache that keeps the last good answer while PlayHQ is down.
