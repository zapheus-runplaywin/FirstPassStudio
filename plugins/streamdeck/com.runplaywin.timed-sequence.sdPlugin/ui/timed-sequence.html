wait 5sDelay. 500ms, 90, 1m30s, 2h, 00:02:00

open <target>Open a URL, file, folder or app
run <command>Run a shell command and wait for it to finish
start <command>Launch a command without waiting
http POST <url> [body]Webhook / API call. Also get <url>, post <url> {...}
keys ctrl+shift+sPress a combo (several separated by spaces). Mods: ctrl, shift, alt/option, cmd (Mac)
type helloType text into the focused window
obs scene Full TimeSwitch OBS to a scene
obs show WinnerShow a source in the current scene. Also hide and toggle. Name the scene with obs show Winner in Full Time; put names containing " in " in quotes
ok / alertFlash the key
log <text>Write to the plugin log
